## Mistakes stop at compile time

Each diagnostic carries its error code from the specification. The language
server runs the same compiler, so your editor shows these as you type.

```zyl
(defn area (s)
  (match s
    (Circle r (* 3 (* r r)))))
```

```text
error[E_NON_EXHAUSTIVE_MATCH]: match over `Shape` does not cover variant `Rect`
  --> shapes.zyl:4:3
   |
 4 |   (match s
   |   ^
   = help: add an arm for that variant, or a `_` catch-all
```

## The compiler reproduces itself, byte for byte

<img src="/zyl/parry.svg" alt="Parry the Owl, the Zyl mascot" class="parry" />

Zyl's compiler and runtime are written in Zyl. The repository commits the
compiler's own assembly as a seed, and every build checks that the seed is
still a fixed point.

<Steps>

1. **Link the seed.** The committed assembly, `stage2.s`, is linked with `cc` into stage 1. No other toolchain is involved.

2. **Rebuild from source.** Stage 1 compiles the compiler's source. The assembly it emits, and the runtime's, must match the committed seed exactly.

3. **Close the loop.** Stage 2 compiles the same source again. If its output differs by a single byte, the build fails.

</Steps>

```sh
git clone https://github.com/larrydewey/zyl.git
cd zyl && ./boot.sh
```
