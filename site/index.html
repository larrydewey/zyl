Hygienic · Homoiconic · Hardened

Zyl is a Lisp for systems programming. It has region-based memory, capability types and sound type inference, and it compiles to static x86_64 executables with no libc, assembled and linked by the compiler itself. Same source, same binary, every time. The compiler is written in Zyl and builds itself with nothing but cc.

$ git clone https://github.com/larrydewey/zyl.git
$ cd zyl && ./boot.sh

the language

A Lisp that knows where every byte lives.

S-expressions and hygienic macros on top. Underneath, a compiler that decides memory placement, checks aliasing and rejects nondeterminism before your program runs.

(with-region (arena ...) body)

Region-based memory

No garbage collector and no free. Escape analysis places each allocation in the call's own region, the caller's result region or the heap. A call's region is released when it returns.

TCap · TMut

Capability types

Shared values are immutable. Only a let-mut binding is exclusive and assignable. Struct fields cannot be mutated in place.

Sound type inference

Hindley-Milner inference with traits resolved statically. Write no annotations and still get every type error reported at once.

Chapter 15

Actor concurrency

Actors own isolated state and talk over typed single-sender channels, a Kahn process network: receive blocks and there is no select, so the output is the same under every schedule. A message cannot carry a let-mut variable.

Hygienic macros

Macros expand innermost-first with gensym hygiene, quasiquote and splicing. Code is data, and generated names never capture yours.

Contracts

Preconditions, postconditions, invariants, recover and checkpoint. Profiles pick panic, warn or strip, and contracts never change the program's meaning.

Bounded FFI

Every foreign call names its symbol literally and carries a timeout in milliseconds. An overrun raises E_FFI_TIMEOUT. Secrets must be pinned before they cross.

Constant-time secrets

A Secret type for key material and a standard cryptography library written for constant-time execution.

Packages and tooling

Manifests, a lock file, minimal version selection and an Ed25519-verified index. A REPL, a language server and a VS Code extension ship with the compiler.

Chapter 35

self-hosting

The compiler reproduces itself, byte for byte.

Zyl's compiler and runtime are written in Zyl. The repository commits the compiler's own assembly as a seed, and every build checks that the seed is still a fixed point.

  1. Link the seedThe committed assembly, stage2.s, is linked with cc into stage 1. No other toolchain is involved.
  2. Rebuild from sourceStage 1 compiles the compiler's source. The assembly it emits, and the runtime's, must match the committed seed exactly.
  3. Close the loopStage 2 compiles the same source again. If its output differs from stage 2's by a single byte, the build fails.
